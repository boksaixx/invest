### 워크숍 도구

강의실에서 손으로 했던 것을 그대로 옮겼습니다. 입력값은 **어디에도 저장되지 않습니다**
(서버로 보내지 않고, 화면을 벗어나면 사라집니다).

1. **5 Why** (6장) — 한 단계를 채워야 다음 "왜?"가 열립니다
2. **HMW 문장 만들기** (6장) — 문장의 넓이를 '너무 좁음 / 적절함 / 너무 넓음'으로 짚어 줍니다
3. **"Yes, And" 2분 실험** (7장) — 규칙만 바꿔 같은 2분을 두 번 돌려 보세요
4. **임팩트 × 실행 가능성 매트릭스** (7장) — 포스트잇을 끌어다 놓거나 눌러서 옮깁니다
5. **10x 리프레이머** (5장) — 10%안과 10배안을 나란히, NASA의 세 계단까지

## 배포 (Vercel)

이 저장소를 Vercel에 그대로 연결하면 끝입니다. 빌드 설정을 따로 만질 필요가 없습니다.

1. [vercel.com/new](https://vercel.com/new) → 이 저장소 **Import**
2. Framework Preset이 **Next.js**로 잡히는지만 확인 (자동으로 잡힙니다)
3. **Deploy**

환경변수도, 데이터베이스도, API 키도 필요 없습니다. 전부 정적으로 미리 만들어지는
페이지라 접속 주소만 열네 명에게 공유하면 됩니다.

> 로그인이나 비밀번호는 두지 않았습니다. 주소를 아는 사람은 누구나 볼 수 있으니
> 링크 공유 범위만 신경 써 주세요. 나중에 막고 싶으면 Vercel의
> Deployment Protection(Password) 기능을 켜면 됩니다.

## 원고를 이어 붙이려면

3부(11장 여덟 가지 발견, 12장 월요일 아침의 플레이북, 에필로그, 부록)는 아직
웹으로 옮기지 않았습니다. 목차와 쪽수는 인쇄본대로 들어가 있고, 본문 자리만 비어 있습니다.

`content/part3.ts`에서 해당 장의 `blocks` 배열을 채우고 `pending: true`만 지우면
나머지 장과 똑같은 형식으로 붙습니다. 쓸 수 있는 블록은 `content/types.ts`에 정의돼
있습니다.

```ts
{ t: "p",     text: "본문 문단" }
{ t: "h",     text: "중간 제목" }
{ t: "quote", text: "인용문", by: "말한 사람" }
{ t: "photo", caption: "사진 설명" }
{ t: "tip",   label: "TIP", title: "제목", text: "내용" }
{ t: "table", caption: "표 제목", head: [...], rows: [[...]] }
{ t: "facts", title: "요약", items: [{ k: "항목", v: "내용" }] }
{ t: "steps", title: "단계", items: [{ n: "01", head: "제목", body: "설명" }] }
{ t: "split", left: { head, body }, right: { head, body } }
{ t: "sketch", label: "FIELD SKETCH", title: "제목", blocks: [ ...중첩 블록 ] }
{ t: "takeaways", title: "세션을 닫으며", items: [{ head, body }] }
```

### 사진에 대해

인쇄본의 도판은 넣지 않고 캡션만 `PHOTO` 자리로 남겨 두었습니다. 실제 사진을 넣으려면
`public/photos/`에 파일을 두고 `photo` 블록에 경로 필드를 하나 추가하면 됩니다.
